# Justin Brisson Portfolio

Personal landing page and portfolio for Justin Brisson (djnightmare9909).

## Overview

This project is built using modern web technologies to provide a fast, responsive, and visually appealing portfolio.

### Tech Stack

- **Framework:** [React 19](https://react.dev/) with [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** [Motion](https://motion.dev/)
- **Backend/Server:** Node.js with [Express](https://expressjs.com/) (when applicable)
- **AI Integration:** Google GenAI SDK (`@google/genai`)
