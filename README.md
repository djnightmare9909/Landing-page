# Justin Brisson Portfolio

Personal landing page and portfolio for Justin Brisson (djnightmare9909).

## Overview

This project is built using modern web technologies to provide a fast, responsive, and visually appealing portfolio.

### Tech Stack

- **Framework:** [React 19](https://react.dev/) with [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** [Motion](https://motion.dev/)
- **Backend/Server:** Node.js with [Express](https://expressjs.com/) (when applicable)
- **AI Integration:** Google GenAI SDK (`@google/genai`)

## Setup & Installation

To run this project locally, follow these steps:

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Environment Variables:**
   Create a `.env` file based on `.env.example` if your application requires any secret keys (such as the Gemini API key).

3. **Start Development Server:**
   ```bash
   npm run dev
   ```
   The application will start in development mode, generally accessible at `http://localhost:3000`.

## Build

To create a production-ready build:

```bash
npm run build
```

This will output the static files or bundled application to the `dist/` directory.
